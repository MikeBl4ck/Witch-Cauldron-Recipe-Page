# FRZ’s Apothecary

Welcome to **FRZ’s Apothecary**, a themed recipe website styled like an ancient grimoire. I built this project using semantic HTML and custom CSS to practice my frontend web development skills and explore creative page layouts.

## Project Details

**Made By:** Michael Black  
**Started:** November 9th, 2026  
**Finished:** November 16th, 2026  
**Total Work Time:** ~17 Hours  
**Character Inspiration:** Qifrey from _Witch Hat Atelier_

## Site Breakdown & Code Stats

**Landing Page**  
The main entry point into the apothecary, welcoming visitors with an atmospheric grimoire aesthetic and navigation to the rest of the site.  
_(43 Lines HTML, 106 Lines CSS)_

**About The Witch**  
A dedicated profile page featuring a portrait and background lore introducing the apothecary's resident witch and magical craft.  
_(79 Lines HTML, 219 Lines CSS)_

**Potion Brewing Guide**  
The core recipe collection showcasing a three-course magical menu complete with ingredients and brewing instructions for the **Essence of Twilight** elixir, **Nightshade Stew**, and **Lunar Shards: Azure**.  
_(477 Lines HTML, 379 Lines CSS)_

**Kitchen Utilities**  
An essential catalog of magical tools, cauldrons, and apothecary equipment needed to prepare and brew the recipes safely.  
_(253 Lines HTML, 300 Lines CSS)_

**Total Code Written:** 852 Lines HTML, 1,004 Lines CSS

## What I Learned

Building this project helped me sharpen my core web design fundamentals. I focused on structuring clean multi-page HTML documents, styling cohesive color palettes and custom typography, and organizing content into a readable, thematic layout.
